MediaFlow - Iteration 3 - things done (as of 2026-11-01)

FEATURES
1. Overnight waking hours. A bedtime earlier on the clock than the wake-up
   time is read as past midnight. Free time is split at midnight so each
   date keeps its own gaps, suggestions and reminders.
2. Forgot-password by email. One-use expiring link, same "check your email"
   reply whether or not the address exists, signs the user in on success and
   confirms their email at the same time. A mail server outage shows a
   message instead of an error page.
3. Change password for signed-in users, linked from the menu.
4. First-use walkthrough. A five-step checklist on Today, ticked from the
   data in any order, gone when finished or hidden with one click.
5. Richer reviews. Five-star picker, required "worth the time?" verdict,
   headline, spoiler fold, and a share switch.
6. Community reviews. Shared reviews appear on the catalog page for the same
   title, with an average rating and the share who said it was worth it.
7. Reviews page summary, filter by media type, and sort by date, rating or
   title.
8. One priority format everywhere: "P4 - High", in the backlog dropdown,
   edit form, suggestion cards, Today and catalog pages.
